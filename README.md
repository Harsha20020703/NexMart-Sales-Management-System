 NexMart - Sales Management System

Project Overview
NexMart is a Java-based Sales Management System developed as an
Enterprise Application Development project. The system provides
functionality for managing products, customers, suppliers, sales,
inventory and generating reports.

 Main Features
- User Login
- Dashboard
- Product Management
- Inventory Management
- Customer Management
- Supplier Management
- Sales Management
- Sales Reports
- Customer Purchase History
- Database Integration
- Exception Handling and Validation

 Technologies Used
- Java
- MySQL
- JDBC
- JasperReports
- NetBeans
- Launch4j

 Database
Database: `nexmart`

The database can be created using:

`nexmart_setup.sql`

 Deployment
The repository includes:
- `NexMartApp.jar`
- `NextMart.exe`
- `NextMart.xml`

 Default Login
Username: `admin`
Password: `admin123`

 Project Structure
- `src/nexmart` - Java source code
- `lib` - External libraries
- `nexmart_setup.sql` - Database setup script
- `NexMartApp.jar` - Java application
- `NextMart.exe` - Windows executable
- `NextMart.xml` - Launch4j configuration
